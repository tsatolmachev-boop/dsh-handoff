# Быстрые заметки

Пакет DSH, добавляющий один пункт в левую боковую панель и страницу
быстрых заметок, которая открывается по нажатию на него. Заметка хранится
в localStorage браузера: ничего не отправляется на Host и не попадает в модель.

## Файлы

| Файл | Назначение |
| --- | --- |
| `package.json` | Манифест пакета: патч Host и объявление клиентского модуля `dsh.client`. |
| `cordis.patch.yml` | Вставляет строку плагина в композицию профиля. |
| `index.js` | Host-половина; сервисы Host не нужны. |
| `client.js` | Клиентская половина; регистрирует иконку боковой панели и страницу `main`. |
| `locale/ru.json`, `locale/en.json` | Название и описание для менеджера плагинов. |
| `icon.svg` | Иконка для менеджера плагинов. |

## Регистрация

- `sidebar.panellist` с id `quick-notes-ru` (order 20) — кнопку, доступную
  подпись, подсказку и состояние выбора рисует сама боковая панель.
- `main` с ключом `quick-notes-ru` — страница, которая открывается по нажатию
  на пункт боковой панели.

## Установка

Из сессии, запущенной в профиле:

```text
plugin_manager({ action: "install_bundle", target: "<абсолютный путь к этой папке>" })
```

Пакет устанавливается в текущий профиль и действует во всех его сессиях.
